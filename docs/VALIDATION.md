# 验证边界

公开版 0.1.0 在 Windows 上验证以下内容：

- Node 检查：认证管道、错误 ticket 拒绝、项目隔离、消息去重、原生历史分页、可见文字过滤、桌面 SDK 方法映射、安装预检无写入、重复安装、升级后回退、冲突文件拒绝、部分写入失败回滚、监控关闭/检查/修复分支。
- Python 适配器检查：使用已安装 Connector 2.0.3 的真实协议类型和临时 KV，验证会话身份、模型目录、消息发送的幂等边界、审批、启动失败保活、版本探测、重连与取消。
- PowerShell 安装和卸载脚本语法检查；临时 Connector 目录的安装/卸载冒烟测试与可选计划任务测试。

隔离检查不登录真实账号、不发送真实消息、不读取个人会话、不修改正在运行的安装。应用更新后需再次进行真实协议和界面验证。

历史定制环境中 WorkBuddy 5.8.4 + 自托管 Agents Anywhere 2.0.3 完成过真实新建、续聊、Deepseek-V4.1-Flash 选择及重启恢复。该环境的地址、账号、会话、截图和认证状态不包含在公开仓库。公开版通用路径安装、监控开关和回退行为使用独立临时环境验证；尚未在其他用户的干净 Windows 电脑和所有分发包上验收。
